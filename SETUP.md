# Второй дилерский сайт — пошаговая настройка

Сайт: https://unus777.github.io/almaly-dealers-prototype/ (репозиторий `Unus777/almaly-dealers-prototype`).
Главный дилерский сайт `almaliceramicc/almaly-dealers` этот сайт **только читает** и никак не меняет.

Что работает сразу после публикации, без настройки:
- каталог, фото, остатки (остатки — живые, из главного сайта при каждом открытии страницы);
- переключатель «Наличные / Безнал с НДС», калькулятор, 3D-примерочная;
- у товаров без цены — «Цена по запросу», их всё равно можно добавить в заявку;
- кнопка «Отправить менеджеру» до шага 1 предлагает WhatsApp и звонок.

Нужно настроить один раз: приём заявок (шаги 1–2), токен для цен (шаг 3), уведомления на телефон (шаг 4).

---

## Шаг 1. Google Apps Script: таблица заявок и push

1. Откройте https://sheets.new — создастся новая таблица. Назовите её **«Заявки дилерский сайт 2»**.
2. В таблице: **Расширения → Apps Script**.
3. Удалите всё в файле `Код.gs` и вставьте целиком содержимое файла `apps-script/Code.gs` из этой папки. Нажмите 💾 «Сохранить».
   (Необязательно: ⚙ «Настройки проекта» → включить «Показывать файл манифеста appsscript.json» и вставить `apps-script/appsscript.json` — там уже стоит часовой пояс Москвы.)
4. Вверху выберите функцию **`setup`** → **▶ Выполнить**.
   Google спросит доступ: «Проверить разрешения» → ваш аккаунт → «Дополнительные настройки» → «Перейти на страницу проекта (небезопасно)» → «Разрешить». Это ваш собственный скрипт.
5. Внизу откроется «Журнал выполнения». Там будет строка **«КЛЮЧ МЕНЕДЖЕРА: …»** — скопируйте ключ в заметки телефона. Его вводят на странице заявок `manager.html`. Никому не пересылайте.
   Если ключ потеряли — снова запустите `setup` (покажет тот же ключ). Если ключ узнал посторонний — запустите `rotateManagerKey`.
6. **Развернуть → Новое развёртывание** → ⚙ «Тип» → **Веб-приложение**:
   - Описание: `Заявки сайт 2`
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
   → **Развернуть** → скопируйте **URL веб-приложения** (заканчивается на `/exec`).
7. Проверка: откройте этот URL в браузере — должно показаться `{"ok":true,"service":"almaly-dealers-2",…,"ready":true}`.

В таблице появятся листы «Заявки» (каждая заявка — строка, статус можно менять прямо там) и «Подписки» (устройства с уведомлениями).

> Если позже поменяете `Code.gs`: **Развернуть → Управление развёртываниями → ✏ → Версия: «Новая версия» → Развернуть**. Адрес `/exec` при этом не меняется.

## Шаг 2. Вставить адрес в сайт

В файле `config.js` замените строку

```js
REQUESTS_URL: '',
```

на

```js
REQUESTS_URL: 'https://script.google.com/macros/s/…ваш…/exec',
```

и опубликуйте (на Mac в папке репозитория):

```bash
git add config.js && git commit -m "Заявки: адрес Apps Script" && git push origin main
```

Через 1–2 минуты кнопка «Отправить менеджеру» начнёт отправлять заявки в таблицу.

## Шаг 3. Токен GitHub для редактора цен

Цены хранятся в файле `prices.json` сайта. Редактор цен сохраняет его через GitHub — для этого нужен токен.

1. https://github.com/settings/personal-access-tokens/new (GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token).
2. Token name: `Цены дилерский сайт 2`. Expiration: например, 1 год.
3. Repository access: **Only select repositories** → `Unus777/almaly-dealers-prototype`.
4. Permissions → Repository permissions → **Contents: Read and write** (Metadata: Read-only добавится сам). Больше ничего не нужно.
5. **Generate token** → скопируйте `github_pat_…`.
6. Откройте https://unus777.github.io/almaly-dealers-prototype/#admin (или ссылку «Цены» внизу сайта) → вставьте токен → «Войти».
   Галочка «Запомнить на этом устройстве» — токен останется только в этом браузере. Без галочки — до закрытия вкладки.
7. Впишите цену **за наличные, ₽/м²**. Безнал считается сам по правилу «нал + 12 %, округление до 10 ₽» (правило меняется вверху и тоже сохраняется). Чтобы вписать безнал вручную — выключите переключатель «Авто» в строке. Пустая цена = «Цена по запросу».
8. Нажмите **«Сохранить на сайт»** — все изменения уйдут одним коммитом. У посетителей новые цены появятся через 1–2 минуты.

Токен никуда не отправляется, кроме api.github.com, и в репозиторий не попадает. Отозвать: та же страница настроек GitHub → токен → Delete.

## Шаг 4. Страница заявок и push-уведомления

Адрес: https://unus777.github.io/almaly-dealers-prototype/manager.html

**Android / компьютер (Chrome, Edge, Firefox, Safari на macOS 13+):**
1. Откройте адрес → введите ключ менеджера (шаг 1.5) → «Войти».
2. «Включить уведомления» → «Разрешить».
3. «Проверить уведомление» — должно прийти «Проверка уведомлений».
4. На Android удобно установить как приложение: меню ⋮ → «Установить приложение» / «Добавить на главный экран».

**iPhone (iOS 16.4 и новее):**
1. Откройте адрес в **Safari**.
2. «Поделиться» ⬆︎ → **«На экран „Домой“»** → «Добавить».
3. Откройте **«Заявки»** с экрана «Домой» (не из Safari!), введите ключ ещё раз (у приложения отдельное хранилище) → «Включить уведомления» → «Разрешить».
4. «Проверить уведомление».

Каждая новая заявка приходит уведомлением «Новая заявка Д2-…» с именем, телефоном и суммой. Нажатие открывает список, где можно позвонить, написать в WhatsApp и поменять статус (Новая → В работе → Счёт выставлен → Закрыта / Спам). Уведомления можно включить на нескольких устройствах.

## Шаг 5. Автосинхронизация каталога и фото

Файл `.github/workflows/sync.yml` каждые 30 минут сверяет сайт с главным дилерским сайтом: новые артикулы, названия, упаковка, остатки, фото. Коммит делается только если что-то поменялось.

1. После первой публикации откройте https://github.com/Unus777/almaly-dealers-prototype/actions — если GitHub попросит, нажмите «I understand my workflows, go ahead and enable them».
2. «Синхронизация с главным сайтом» → **Run workflow** — первый запуск вручную.
3. Чистые кадры без надписей (`img2/`), которые уже отобраны, сохраняются. Для новых артикулов и новых фото скрипт сам подбирает кадр интерьера и фактуры (распознавание текста RapidOCR). Такие товары в `photos-manifest.json` помечены «кадры подобраны автоматически» — стоит глянуть их глазами.

GitHub отключает расписание, если в репозитории 60 дней не было никаких коммитов. Тогда на той же странице Actions будет кнопка «Enable workflow».

## Что нельзя класть в репозиторий

Репозиторий публичный, всё в нём видно всем. Секретов в коде сайта нет. Никогда не коммитьте:
- токен GitHub (`github_pat_…`): он живёт только в браузере;
- ключ менеджера и ключи VAPID: они живут только в «Свойствах скрипта» Apps Script;
- файлы `.env`, `*.pem`, `*.key`, `secrets/`, `owner-access-link.txt`, `*token*.txt` (они уже в `.gitignore`);
- `node_modules/` и `tests/shots/`.

## Если что-то не работает

| Симптом | Что сделать |
|---|---|
| «Онлайн-приём заявок ещё настраивается» | не заполнен `REQUESTS_URL` в `config.js` (шаг 2) |
| «Не удалось отправить…» | открыть URL `/exec` в браузере. Если нет `"ok":true`, развернуть заново (шаг 1.6, доступ «Все») |
| Редактор цен: «токен не подходит» | токен истёк или удалён, создать новый (шаг 3) |
| Редактор цен: «нет права Contents» | в токене не выбран репозиторий или право Contents: Read and write |
| Уведомления не приходят | на странице заявок «Проверить уведомление». На iPhone открывать только с экрана «Домой». В Apps Script запустить `testPush`, в журнале будет ответ служб push |
| Новые товары не появились | Actions → «Синхронизация с главным сайтом» → посмотреть последний запуск / Run workflow |
